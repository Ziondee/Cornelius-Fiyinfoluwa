# 👋 Why I Approach Data Differently

Before I learned to build dashboards, I learned to question evidence.

My background in **Industrial Chemistry** taught me a principle that shapes every analytics project I work on:

> **A conclusion is only as reliable as the process that produced it.**

In science, results aren't accepted because they look convincing — they're accepted because they've been questioned, tested, and validated. That same mindset defines how I approach data:

- ✔ Understand the business problem before opening Power BI
- ✔ Validate data before drawing conclusions
- ✔ Translate technical findings into business language
- ✔ Measure success by business impact — not visual complexity

I don't simply want to build dashboards. **I want to build confidence in business decisions.**
